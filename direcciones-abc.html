3 direcciones para la pantalla "Hoy"

Misma pantalla, mismo contenido — cambia la personalidad. Las tres nacen de tu cliente ideal: una pareja que administra el gasto del hogar sin que eso les cueste la calma. Desliza para ver las tres y dime cuál se siente más "tú" — puedes elegir una completa, pedirme que combine partes de dos, o ajustar un detalle puntual.

Dirección A

Hogar en Calma

Cálida y editorial, como una libreta de cuentas bien llevada. Verde salvia para lo que se ahorra, terracota para el detalle humano. Pensada para que abrir la app se sienta como sentarse a la mesa, no como entrar a un banco.
